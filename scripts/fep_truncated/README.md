# Truncated-site mutation FEP (Jorgensen-shaped)

OpenMM alchemical free-energy calculations on a **truncated NNRTI pocket**, following the
spirit of Rizzo/Jorgensen (2000) and the later HIV-RT MCPRO lineage (Smith et al., 2007).

This replaces the full-protein Perses workflow in `scripts/fep_jorgensen/`, which completed a
V106A pilot but is **not** suitable for panel scale-up (see pilot findings there).
