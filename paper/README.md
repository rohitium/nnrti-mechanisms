# paper/

The deliverable, and only the deliverable.

| path | what |
|---|---|
| `submission/` | Exactly what the journal receives: the manuscript, the supplementary text, Supplementary Tables 1–4, and the figure PDFs. |
| `tables/` | Derived tables pasted into the main text. Regenerated by `workflows/05_manuscript_artifacts.sh`; never hand-edited. |
| `sources/` | Figure assembly: the PowerPoint that composes the panels, the ACS Word template, and two SVG sources. |
| `ARTIFACTS.md` | **The authority.** Every numbered figure and table, mapped to the script that produces it and the file it lands in. |

Supplementary Tables 3 and 4 are written directly into `submission/` by their
generator — there is deliberately no second copy elsewhere in the repo. A
duplicated workbook is how Supplementary Table 3 came to disagree with Table 2
about G190E, in sign, for three weeks.

Working notes from the drafting rounds — audits, paragraph drafts, change
records — are in `docs/decisions/manuscript-notes/`. Earlier drafts and figure
sets are in the external archive; see the repository README.
