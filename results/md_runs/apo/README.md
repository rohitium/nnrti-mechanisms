# Apo MD runs

Ligand-free replicates use `<genotype>/rep_NN/`, with a production target of
100 ns per replicate (50,000,000 steps at 2 fs).

See [MD run data](../../../docs/methods/md-run-data.md) for file definitions,
completion checks, resume handling and PBC validation. Analysis protocols and
matched apo/holo windows are described in the [reproduction guide](../../../REPRODUCE.md).
