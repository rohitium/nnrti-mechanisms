# Results

`analysis/` contains derived tables and plots. Use [paper/ARTIFACTS.md](../paper/ARTIFACTS.md) to identify the current manuscript artifacts: filenames retain historical figure numbers and are not reliable publication labels.

Authoritative numerical inputs are `analysis/fep_pmx/panel_ddg.csv`, `analysis/binding_energy/tables/ddg_full.csv`, and `analysis/structural_metrics/tables/structural_metrics_per_replicate.csv`. Other files include diagnostics and superseded analyses; do not infer that every CSV is used in the paper.

`md_runs/` contains local holo and apo trajectories/run records. Large runtime files are ignored and require separate backup. See [MD run data](../docs/methods/md-run-data.md) before copying, resuming or deleting anything.
