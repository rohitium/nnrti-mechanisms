# figures/

Curated, **manuscript-facing** figures — the ones that go into the paper or a
talk, exported deliberately and kept stable.

This is intentionally *separate* from the many per-run / per-analysis plots that
live under `results/` (e.g. `results/analysis/fep_pmx/panel_ddg_vs_experiment.png`,
per-leg `work_dist.png`, `crooks_overlap/`, `lambda_profiles/`). Those are
regenerated by analysis code and stay with their results.

Convention:
- Analysis code writes plots under `results/…` (reproducible, regenerable).
- When a plot becomes a manuscript deliverable, export/copy a stable version
  here with a descriptive, versioned name (e.g. `fig3_ddg_vs_experiment_v2.png`).
- Reference the source result path in the figure's caption or a sidecar note so
  provenance is traceable back to the generating run.

Point paths at this directory via `from src.paths import FIGURES`.
