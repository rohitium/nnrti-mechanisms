# Historical material

This is the sole archive directory. Nothing here is the current submission or an instruction to edit it. Use [the submitted package](../revisions/submission-ready/) and [artifact map](../paper/ARTIFACTS.md).

- `original-submission/`, `original-figure-deck.pptx`, `original-table-3.csv`: September submission and superseded figure/table sources.
- `revision-history/`: earlier working documents, audit records, supporting assets and historical status notes.
- `analysis-updates/`: intermediate November analysis comparisons and draft SI additions.
- `revision-status.md`, `discussion-literature-support.md`: historical revision notes.
- `local-snapshots/`, `retired-upload-files/`, and revision-history backup copies: local recovery material excluded from GitHub.

`MOVE-MANIFEST-20261110.json` records the consolidation. An older move manifest within revision-history records earlier moves relative to the previous layout. Backups are retained locally; they are not all duplicated in Git. Production simulation directories were left in place. Local recovery directories were relocated intact. No raw simulation data was deleted.

`legacy-document-edits/` preserves one-off scripts for superseded drafts. Their relative paths and hardcoded document names describe the old layout; retain them as history, not runnable production steps.
